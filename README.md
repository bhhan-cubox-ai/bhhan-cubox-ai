## 🧑‍💻 About Me

- AI 모델을 실제로 사용할 수 있는 시스템으로 연결하는 **AI Engineer**입니다.

- **문제에 필요한 기술을 선택하고, 동작하는 제품까지 구현하는 과정**에 관심이 많습니다.  
  모델 연동뿐 아니라 데이터 처리, 백엔드 API, 사용자 인터페이스와 배포 환경을 함께 다루며, 현장의 요구사항을 구현으로 연결하는 **Forward Deployed Engineer**로 성장하고자 합니다.

- **창의성은 지식의 결합에서 나온다**는 신념을 가지고 있습니다.  
  새로운 기술을 배우는 데서 그치지 않고 직접 구현하며, 결과를 확인하고 개선하는 과정을 중요하게 생각합니다.
